# 1_plan.md: Retro CLI Portfolio Site Plan (Updated)

이 문서는 레트로 CLI 감성의 포트폴리오 사이트와 이를 관리하기 위한 GUI 도구 제작 계획을 담고 있습니다.

## 1. 목표 및 컨셉
- **컨셉**: 80-90년대 터미널(CMD/PowerShell) 또는 고전 게임 감성.
- **주요 기능**:
    - 터미널 인터페이스 네비게이션 (`ls`, `cd`, `help`, `cat`).
    - YouTube/이미지/음악 임베드 지원.
    - **폰트 전환 기능**: 사용자가 Galmuri14와 zpix 폰트 중 선택 가능.
    - **사이트 관리 GUI**: 코딩 없이 포트폴리오 항목을 추가/수정할 수 있는 관리자 화면.
- **비용**: $0 (GitHub Pages 무료 호스팅).

## 2. 기술 스택 및 구조
- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Data**: `content.json` (모든 포트폴리오 데이터 저장).
- **Admin GUI**: 
    - **옵션 A (브라우저 내장 에디터)**: 사이트 내 특정 경로(예: `/admin`)에서 데이터를 수정하고, 수정된 `content.json`을 다운로드하여 프로젝트에 덮어쓰는 방식.
    - **옵션 B (로컬 관리 도구)**: 로컬에서 실행되는 간단한 HTML/JS 페이지를 통해 파일을 직접 수정 (가장 추천).

## 3. 작업 분담

### Gemini CLI가 수행할 부분
1. **프로젝트 초기화**: `index.html`, `style.css`, `script.js` 및 데이터 구조 설계.
2. **레트로 엔진 구현**: CRT 효과, 텍스트 타이핑 효과, 폰트 스위처 구현.
3. **CLI 인터페이스**: 가상 파일 시스템 및 명령어 처리 로직.
4. **관리 GUI(Admin Panel) 개발**: 
    - 포트폴리오 항목(제목, 링크, 설명, 태그) 추가/수정/삭제 UI.
    - 실시간 프리뷰 기능.
    - `content.json` 생성/업데이트 로직.
5. **배포 프로세스**: GitHub Pages 연동 가이드 제공.

### 사용자가 수행할 부분
1. **폰트 확인**: 현재 `font/` 폴더 내 `Galmuri14.ttf`, `zpix.ttf` 파일 사용 확인 (완료).
2. **콘텐츠 입력**: 제공될 관리 GUI를 통해 실제 작업물 데이터 입력.
3. **GitHub 업로드**: 완성된 코드를 본인의 GitHub 저장소에 push.

## 4. 상세 개발 로직 (GUI 관리)
- 관리 도구에서 작업물을 추가하면 `content.json` 파일의 배열에 객체 형태로 저장됩니다.
- 예: `{ "type": "video", "title": "My Animation", "url": "youtube_link", "tags": ["animation", "2D"] }`
- 사이트 메인 로직은 이 JSON을 읽어와 터미널 화면에 리스트업합니다.

- 현재 사용자가 실제 데이터를 입력하며 테스트 가능한 상태.
